# review-layout: what is checked

- State (verify.py): the note is unchanged on disk and the editor still runs.
- Looks (output.visual): the desktop screenshot the bench takes matches the
  reference (mean SSIM at least 0.99, the status bar's line and column
  masked), the line-number gutter is at the left of the text area and the
  status bar is at the bottom of the window.
