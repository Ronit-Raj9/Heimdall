# Set up the editor for review

A Linux desktop is open with the note `~/Documents/note.txt` in the
Mousepad text editor. You reach the desktop only through its MCP tools
(screenshot, click, type, key, ...).

Set the editor up for review:

- turn on line numbers;
- show the status bar.

Leave everything else as it is: do not edit or save the note, and do not
turn on any other bar or panel. Close any menu you open.
