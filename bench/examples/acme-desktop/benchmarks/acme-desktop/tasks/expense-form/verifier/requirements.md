# expense-form: what each check holds, and why

| Check | Instruction |
|---|---|
| `submitted_once` | "submit it once" |
| `employee` | "I am Dana Whitfield" (case ignored) |
| `date` | "on 12 March 2026", in the form's YYYY-MM-DD format |
| `amount` | "86.40 EUR" (a comma or a currency sign is accepted) |
| `category` | "it counts as travel": the form's Travel category |
| `description_names_taxi` | "my taxi from the airport" |
| `receipt_ticked` | "I have attached the receipt" |
