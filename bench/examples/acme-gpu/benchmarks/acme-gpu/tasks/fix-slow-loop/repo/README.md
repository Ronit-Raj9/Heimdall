# churn-model

Nightly training of Acme's churn classifier (fictional data, generated by
`data.py`).

- `data.py`: `make(data_seed)` returns 20,000 labelled points.
- `model.py`: the classifier, `MLP()`.
- `train.py`: `train(x, y, device)` returns the trained model;
  `python train.py --data-seed 11 --out model.pt` prints the time.
- `tests/`: `python -m pytest -q tests` (needs the GPU).

The container has PyTorch 2.15 (CUDA 13.2); no network.
